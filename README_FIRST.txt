QUICK START GUIDE:

1. REQUIREMENTS:
   - Node.js (LTS version >= v20.0.0 recommended)
   - PostgreSQL (v14 or newer)

2. INSTALLATION INSTRUCTIONS:
   - Refer to documentation/INSTALLATION.md (or root INSTALLATION.md) for complete step-by-step guidance.

3. ENVIRONMENT CONFIGURATION:
   - Copy .env.example to .env
   - Configure your PostgreSQL database credentials and SESSION_SECRET.

4. DEPENDENCY INSTALLATION:
   - Run: npm install

5. DATABASE SETUP & DEMO SEEDING:
   - Run: npm run db:init (or npm run db:seed) to set up tables and seed fictional demo data.

6. SETUP DIAGNOSTIC CHECK:
   - Run: npm run setup:check to verify environment health, DB connectivity, all 23 tables, and demo accounts.

7. STARTING THE APPLICATION:
   - Development mode: npm run dev
   - Production build: npm run build && npm start

8. DEFAULT DEMO CREDENTIALS:
   - Administrator: admin / Demo@1234
   - Doctor: dr.sarah / Demo@1234
   - Receptionist: receptionist / Demo@1234

DOCUMENTATION:
All documentation files (User Guide, Customization, Troubleshooting, Security,
